# 🎮 PORTOFOLIO 8-BIT — Malice Portfolio Website

> *"PLAYER 1 READY"* — An interactive personal portfolio website built with a retro 8-bit / pixel-art arcade aesthetic to showcase projects, skills, and personal space.

---

## ✨ Features
* **Retro Arcade Aesthetic:** Classic pixel typography (`Press Start 2P`), CRT scanlines overlay, and dynamic rising pixel star background.
* **Scroll Animations:** Smooth reveal effects powered by the **Intersection Observer API**.
* **Interactive Skill Tree:** Clickable category cards that open retro modal HP bars showing skill proficiency levels.
* **Dynamic Specialties Grid:** Rendered dynamically using modern JavaScript.
* **Personal Space:** Integrated showcase for Spotify playlist, Discord profile, and Steam gaming status.
* **Quest / Contact Form:** Retro-themed contact form connected to email.
* **Responsive Design:** Optimized for both desktop and mobile viewports with a custom mobile navigation menu.

---

## 🛠️ Built With
* **HTML5** — Semantic page structure
* **CSS3** — Custom properties, CSS Grid, Flexbox, Keyframe animations, CRT scanline overlay
* **JavaScript (Vanilla)** — Dynamic DOM rendering, intersection observers, modal controllers, form handling
